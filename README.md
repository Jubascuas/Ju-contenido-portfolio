# Ju.contenido — Portfolio

Portfolio personal de Julieta Bascuas — Diseñadora Multimedial, Creadora de Contenido, Fotógrafa y Filmmaker.

## Estructura

```
ju-portfolio/
├── index.html          # Página principal
├── assets/
│   ├── hero.jpg        # Foto de fondo del hero
│   ├── diseno/         # Imágenes de diseño (Rainbow, etc.)
│   └── edicion/        # Videos y posters de edición
```

## Cómo agregar contenido

- **Hero**: reemplazá `assets/hero.jpg` con tu foto.
- **Diseño**: agregá imágenes en `assets/diseno/`.
- **Edición**: agregá videos en `assets/edicion/`.
